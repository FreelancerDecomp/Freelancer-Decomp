# Mission trigger conditions (`Cnd_*`)

Reference for every condition a `[Trigger]` section can use in a mission script. A trigger has exactly one condition; its parameters are read **positionally** from the comma-separated value list of the `Cnd_*` line by that condition's `Parse` function.

## File location / how it is found

`Cnd_*` lines are keys inside `[Trigger]` sections of mission script files (story missions `Missions\Mnn\mnn.ini`, generic missions, see [missions.md](missions.md#file-location--how-it-is-found)); the files are opened through `OpenContentDataIni` relative to the Data path. The key names are matched case-insensitively against the factory table `GCndFactory` ([MissionScript.cpp:86](../../src/Content/MissionScript.cpp#L86)); each condition class is in [MissionCnd.cpp](../../src/Content/MissionCnd.cpp). The same condition classes also write/read one line of state in the save game's `[TriggerSave]` section, shown in the "Save line" column where it exists (see [missions-saves.md](missions-saves.md)).

## Conventions

* "Label" = a mission-local object name, group label, or `Player` (see [missions.md](missions.md#conventions-used-in-the-tables)). "nick" = a nickname resolved with `pub::GetNicknameId`; "base"/"system" values are resolved with `pub::GetBaseID` / `pub::GetSystemID` and silently stay 0 if the name is unknown (not validated).
* An id that is 0 (masked `& 0x3fffffff`) means "unset": most conditions then match anything or fail, as noted.
* `inside|outside`: only these two words (`stricmp`) are recognised; any other word leaves the default (`outside`).
* Squared distances: a distance in the INI is squared at load (`d*d`) **only if it is greater than 0** (or not less than 0 for some entries, see each row); a non-positive value is used as is.
* Polled conditions (heartbeat) are evaluated each mission heartbeat; event conditions only when their message arrives. "Wakes on" below names the message ([MissionScript.cpp:86-131](../../src/Content/MissionScript.cpp#L86)). A trigger is also evaluated once without an event when it is activated; many conditions return false for "no parameters" then.
* Types: `str`, `int`, `float`, `bool`, `id` (CreateID), `nick`, as in [missions.md](missions.md#conventions-used-in-the-tables).

### Trigger events used (`Wakes on`)

Heartbeat-polled: `Cnd_True`, `Cnd_Timer`, `Cnd_HasMsn`, `Cnd_InSpace`, `Cnd_InTradelane`, `Cnd_InZone`, `Cnd_CmpToPlane`, `Cnd_DistShip`, `Cnd_DistVec`, `Cnd_DistVecLbl`, `Cnd_DistCircle`, `Cnd_WatchTrigger`, `Cnd_WatchVibe`. Event driven: the others, with the message named in the table. The mapping is the table `GCndFactory` in [MissionScript.cpp:86](../../src/Content/MissionScript.cpp#L86), not configurable from the INI.
