# Freelancer: HD Edition — план совместимости

Статус: исследование и план (2026-10-15); реализовано только то, что перечислено в разделе
«Что есть в порте». Цель: порт запускает данные Freelancer: HD Edition и ведёт себя как HD-установка
**без загрузки плагин-DLL и без байтовых патчей** — каждое изменение HD переписывается обычным C++
в модуле, который владеет retail-функцией, за compile-time переключателем, так что ванильная сборка
остаётся retail-точной. Поэтому `jflp.dll` и `HudShift.dll` в `bin/DACOM.INI` не добавляются: они
патчат жёстко заданные адреса и роняют клиент.

Исследована установка HD v0.7.1 с исходниками плагинов (FLHDE/flplusplus, FLSharp, adoxa, jflp
v1.27). Установленные плагины **старше** публичных исходников: FLSharp 0.8.0 (в исходниках 0.9.2),
flplusplus без touchpad/confine_cursor/vsync/max_fps/direct_ips. Портируется поведение
установленных версий. Таблицы адресов патчей и плагинные ini — в истории git этого файла
(коммиты до сокращения); при работе над пунктом их нужно сверять с листингом заново.

## Что HD меняет

| Слой | Что | Влияние на порт |
|---|---|---|
| DATA | сотни INI, переведённых из BINI в текст; новые модели, ALE, THN, шрифты | только данные; reader принимает текст. Новые ini плагинов: `HudShift.ini`, `ranks.ini`, `Territory.ini`, `storyfactions.ini`, `MultiIntro.ini` |
| Ресурсные DLL | изменённые тексты; новая `Controls.dll` (только `.rsrc`) в `[Resources]`, IDS `0x7xxxx` | данные |
| Статические байтовые патчи | готовые пропатченные exe/DLL (Freelancer.exe, Common, Server, rendcomp, rp8, DALib, ebueula) | переписать как C++ в соответствующих функциях |
| Плагин-DLL | `jflp.dll` и 17 плагинов в `dacom.ini [Libraries]`, `callsign.dll` в `[Initial SP DLLs]` | переписать как C++ |
| Внешние обёртки | `d3d8.dll`, `dinput8.dll`, ReShade | кода не требуют |
| Серверные | `FLHook.dll` и плагины | мультиплеер, после беты |

## Группы изменений

**jflp (widescreen, статистика, мелочи).** Широкоэкранный пересчёт FOV/пропорций/UI-ширины при
каждой смене режима, список режимов без фильтра 4:3 и режим по умолчанию = десктоп, камеры THN;
статистика Power/Engine/Scanner/Tractor/Armor в инфокартах дилера; секторы «C4» вместо «4C»;
Alt+Enter; roll в mouse-flight; 8-way strafe; первая группа оружия активна при запуске; ряд
подавлений FDUMP.

**Байтовые патчи.** Гамма `slider + 0.75`, лимит групп текстур, пул/длина чата, IDS-замены на
`Controls.dll`, пороги HUD (ContactList «Far», круиз-скорость), период обновления групп на NavMap,
ограничение FPS из RTC, убранные EULA/ESRB/мьютекс, VRAM-проверка; в DLL — демпфирование IVP,
дистанция отмены стыковки 50 км, взрывы без спада по расстоянию, сохранения без шифрования, AA/AF как
значения конфигурации (не константы).

**flplusplus.** `lod_scale`, `pbubble_scale`, `character_detail_scale`, `asteroid_dist_scale`,
папки сохранений и скриншотов (PNG через WIC), приватные шрифты из `fonts.ini [FontFiles]` (**нужны
HD-данным**), регенерация `Restart.fl`.

**FLSharp 0.8.0.** Улучшенная синхронизация объектов (интервалы/пороги `CheckForSync`), правки
waypoint, фиксы звука и анимаций оружия, вспышки на каждом стволе, копирование/вставка в
`RichTextEditWin`, список разрешений до 127 режимов, тестовые звуки в настройках, вывод требуемой
репутации, исправления крашей.

**Прочие плагины.** DelayDisplay (задержка/боезапас в списке оружия), HudShift (сдвиг ≈385
HUD-координат под широкий экран; ключуется retail-адресами), numeric, ranks, storyfactions,
Territory, TurretZoom, MultiIntro, WheelScroll, Zone, rus_chat/cyrillic_chat, HUDless, Hail, callsign,
MPRep, gls_workaround.

## Принципы реализации (план)

- Один compile-time переключатель на функцию, `#if`, а не `#ifdef`; каждое место помечено
  комментарием `// HD:`; по умолчанию ванильная сборка не содержит HD-кода.
- Числовые параметры (lod_scale, аргументы TurretZoom, позиции HudShift) читаются при запуске из
  тех же файлов HD, что и у плагинов, чтобы существующая HD-конфигурация работала как есть.
  Присутствие плагина в `dacom.ini` служило выключателем; в порте такая запись должна распознаваться
  вместе с аргументами строки, а неизвестное имя по-прежнему должно падать громко.
- Константы, которые retail читает из общего `.rdata`, в порте — свои литералы у каждого читателя;
  HD-значение надо применять к каждому читателю явно. Для HudShift нужен слой именованных констант
  вместо литералов.
- HD-ветки — намеренные функции, а не долг retail: в `deviations.md` они не идут, статус
  ванильной функции в tracker они не меняют. Пункт, чей hook-функция ещё не `ready_verified`, сначала
  доводят до ванильной точности.

## Решения владельца (2026-10-15)

1. HD-баги переносятся по смыслу, не побайтно: подсказка прицеливания по врагу (J1) остаётся рабочей
   (убирается только FDUMP); коэффициент 0.85 — только у `HUD_Core::DrawBars`, не у короны Солнца и
   звука двигателей; лимитер кадров остаётся `Sleep(1)` (при необходимости — ожидание на
   высокоточном таймере, не busy-wait); кириллический ввод — только для реального cp1251, Latin-1 не
   ломается; `%Z` в `FmtStrSprintf` меняется глобально, только если этого требуют тексты Zone.
2. Патчи, дающие только строки лога, не переносятся.
3. Поведение FLSharp 0.8.0 как установлено; 0.9.2 — в бэклоге.
4. Мультиплеерные пункты (синхронизация, чат, список серверов, MPRep, FLHook) — после беты.

## Что есть в порте

- Широкоэкранный режим «Hor+» — `FREELANCER_WIDESCREEN_SUPPORT` (свойство
  `FreelancerWidescreenSupport` в `src/Directory.Build.props`, по умолчанию включено): камеры
  расширяют фрустум по горизонтали, интерфейс Win3D остаётся 4:3, угловые окна HUD сдвигаются к краям
  экрана сдвигом камеры (`widescreen.h`, `hud_widescreen.*`). Это самостоятельный механизм порта,
  заменяющий jflp-пересчёт и HudShift; он не повторяет их побайтно. Описан в [re/freelancer.md](re/freelancer.md),
  отклонения — в [re/deviations.md](re/deviations.md).
- Остальное (`hd_edition.h`, `FL_HD_*`, свойство `FreelancerEdition`, каталог `binhd\`, `FHdConfig`,
  распознавание плагинов в dacom) **не реализовано**.

## Бэклог вне установленной версии

FLSharp 0.9.2 (исправления краша дилера и фильтра серверов, имена waypoint, групповые отношения,
курсор, камера, лимит света и др.) и новые ключи flplusplus (`touchpad_support`, `confine_cursor`,
`vsync`, `max_fps`, `direct_ips`). Не применённые в установке опции инсталлятора (LevelRequirements,
AdvWideHUD, SkippableCutscenes, TopDownTargetView, Windowed/Borderless, DoNotPauseOnAltTab) —
кандидаты в runtime-настройки.
