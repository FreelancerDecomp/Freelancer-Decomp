# Справочник по INI

[English](../../ini/README.md) · **Русский**

Freelancer настраивается почти целиком через файлы в стиле INI: движок (`DACOM.INI`), главный файл
игры (`freelancer.ini`) и несколько тысяч таблиц данных, на которые указывают `freelancer.ini` и
другие файлы данных. Эта папка документирует для каждого места, где код читает такой файл,
**какие секции и ключи читаются, какого они типа, значения по умолчанию и допустимые значения, и
какой исходный файл их читает.**

Всё здесь написано по исходникам в `src/` (код — первоисточник). Если код не проверяет значение,
на странице указано *не проверяется*. Значения, которые удалось лишь предположить по именам или по
окружающему коду, помечены соответствующим образом. Retail-данные, поставляемые с игрой, не
воспроизводятся; примеры короткие и синтетические.

Начните с [parsers.md](parsers.md) — там описаны два парсера, текстовый и бинарный (BINI) форматы,
синтаксис комментариев и `@include`, позиционные значения и разрешение путей к файлам. Все
остальные страницы опираются на неё.

## Соглашения страниц

- Каждая страница начинается с назначения и абзаца *File location* (имя файла, как строится путь).
- Таблицы ключей используют столбцы **Ключ · Тип · По умолчанию · Значение / допустимые значения ·
  Источник**; *Источник* ссылается на читающий код.
- Позиционные значения (списки через запятую, читаемые по индексу) перечислены в порядке индексов.
- Ключи, которые могут повторяться (одна строка на запись), отмечены в тексте страницы.

## Поддержание актуальности

Когда вы добавляете или меняете чтение INI в `src/`, обновите страницу соответствующей области в
том же изменении. Страницы написаны по коду, а не запуском игры на каждом файле данных.
