# Действия триггеров миссий (`Act_*`)

Справочник по каждому действию, которое может содержать секция `[Trigger]`. Триггер может содержать любое число строк `Act_*`; они выполняются в порядке следования в файле, когда условие триггера становится истинным. Параметры читаются **позиционно** из значений строки, разделённых запятыми, функцией `Parse` каждого действия.

## Расположение файла / как он находится

Строки `Act_*` — это ключи внутри секций `[Trigger]` файлов сценариев миссий (см. [missions.md](missions.md#расположение-файла--как-он-находится)); файлы открываются через `OpenContentDataIni` относительно пути Data. Имена ключей сопоставляются без учёта регистра с таблицей фабрики `GActFactory` ([MissionScript.cpp:143](../../../src/Content/MissionScript.cpp#L143)); классы находятся в [MissionAct.cpp](../../../src/Content/MissionAct.cpp). У действий нет состояния в сохранениях (сохранение записывает только, какие триггеры активны, см. [missions-saves.md](missions-saves.md)).

## Соглашения

* Типы и «label»/«nick» объяснены в [missions.md](missions.md#соглашения-принятые-в-таблицах) и [missions-conditions.md](missions-conditions.md#соглашения). **Необязательное** значение означает, что код проверяет `is_value_empty(i)` и сохраняет значение конструктора по умолчанию, если оно пусто.
* Значения «Quaternion W,X,Y,Z» нормализуются и преобразуются в матрицу при загрузке; нулевой кватернион не проверяется.
* Слова, перечисленные для значения, — единственные, с которыми код сравнивает (`stricmp`, без учёта регистра, если не указано иное); неизвестное слово молча оставляет значение по умолчанию. Сообщения об ошибке нет.
* Там, где булево значение описано словом «true», нижележащий `get_value_bool` принимает ровно `true`/`1`/`false`/`0` (см. [parsers.md](parsers.md)).
* Большинство действий возвращают успех, даже если их цель не существует; случаи, возвращающие неудачу (что важно только для учёта триггеров), не описываются.

## Nag-действия

«Nag» — это принадлежащий миссии объект-наблюдатель, идентифицируемый по nag id, который проигрывает голосовые реплики NPC/NN, пока игрок игнорирует указание. Вся обработка nag приостанавливается, пока `Act_NagClamp` равен `true`. `Act_NagOff` удаляет nag. Два nag по расстоянию используют общий механизм: когда корабль игрока дальше `distance` от цели (текущей позиции объекта или фиксированной точки), запускается таймер на 20 с; при каждом срабатывании, если игрок приблизился менее чем на 900 единиц с последней проверки и по-прежнему дальше `distance`, проигрывается реплика (`nag_pos`, `nag_dst_ship`, `nag_dst_base`, `nag_dst_hole`, `nag_dst_gate`, `nag_dst_tl`, выбирается по типу цели, голосом говорящего). Каждая завершённая реплика nag расходует один из 4 nag; когда они исчерпаны, миссия переводится в `FAIL` с *id текста провала*. Nag заканчивается, когда игрок стыкуется с целью / входит в неё (база, врата, дыра или торговый путь). Если говорящий летит в построении игрока, реплика не проигрывается.
