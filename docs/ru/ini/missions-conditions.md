# Условия триггеров миссий (`Cnd_*`)

Справочник по всем условиям, которые секция `[Trigger]` может использовать в скрипте миссии. У триггера ровно одно условие; его параметры читаются **позиционно** из списка значений в строке `Cnd_*`, разделённых запятыми, функцией `Parse` этого условия.

## Расположение файла / как он находится

Строки `Cnd_*` — ключи внутри секций `[Trigger]` файлов скриптов миссий (сюжетные миссии `Missions\Mnn\mnn.ini`, универсальные миссии, см. [missions.md](missions.md#расположение-файла--как-он-находится)); файлы открываются через `OpenContentDataIni` относительно пути Data. Имена ключей сопоставляются без учёта регистра с таблицей фабрики `GCndFactory` ([MissionScript.cpp:86](../../../src/Content/MissionScript.cpp#L86)); каждый класс условия находится в [MissionCnd.cpp](../../../src/Content/MissionCnd.cpp). Те же классы условий пишут и читают одну строку состояния в секции `[TriggerSave]` сохранения игры; она показана как «Save line» там, где существует (см. [missions-saves.md](missions-saves.md)).

## Соглашения

* «Label» = локальное для миссии имя объекта, метка группы или `Player` (см. [missions.md](missions.md#соглашения-принятые-в-таблицах)). «nick» = псевдоним, разрешаемый через `pub::GetNicknameId`; значения «base»/«system» разрешаются через `pub::GetBaseID` / `pub::GetSystemID` и молча остаются 0, если имя неизвестно (не проверяется).
* Id, равный 0 (после маски `& 0x3fffffff`), означает «не задан»: большинство условий тогда совпадают с чем угодно или не выполняются, как указано.
* `inside|outside`: распознаются только эти два слова (`stricmp`); любое другое слово оставляет значение по умолчанию (`outside`).
* Квадраты расстояний: расстояние в INI возводится в квадрат при загрузке (`d*d`) **только если оно больше 0** (или не меньше 0 для некоторых записей, см. каждую строку); неположительное значение используется как есть.
* Опрашиваемые условия (heartbeat) вычисляются на каждом heartbeat миссии; событийные — только когда приходит их сообщение. Пометка «Просыпается по» ниже называет сообщение ([MissionScript.cpp:86-131](../../../src/Content/MissionScript.cpp#L86)). Триггер также вычисляется один раз без события при активации; многие условия при этом возвращают false из-за «нет параметров».
* Типы: `str`, `int`, `float`, `bool`, `id` (CreateID), `nick`, как в [missions.md](missions.md#соглашения-принятые-в-таблицах).
