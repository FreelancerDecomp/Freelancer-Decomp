# Дыры инвентаря трекера: freelancer.exe `.text`

Часть `.text` у `freelancer.exe` не покрыта ни одним элементом decomp-tracker. Это не ошибка
ingest: в листинге `EXE/Disasm/freelancer.exe.txt` такие байты помечены `??` (Ghidra не создал
функцию), хотя дизассемблер по PE разбирает их как обычный x86. `refresh_module` на том же
экспорте ничего не добавит. Лечение — в Ghidra «Create Function», затем заново экспортировать
`.txt` и `.c` и сделать `refresh_module`.

Почти все непокрытые блоки — выравнивающие `INT3`/`NOP` между функциями. Блоки крупнее 32 байт —
дополнение к критерию полноты порта: «всё, что в трекере, плюс эти блоки». Вставить их через API
трекера без нового экспорта Ghidra нельзя, поэтому они перечислены здесь. Статусы портирования
этих блоков ведутся в `ported_*` соседних функций трекера и в `deviations.md`, не здесь.

Измерение (локальный скрипт, не публикуется): (PE-диапазон `.text` минус объединение интервалов элементов трекера, затем классификация блоков
>= 32 байт по Capstone, vtable-xref из `.rdata` и заметкам соседей). Перезапускать после каждого
нового экспорта листинга Ghidra; числа в отчёт волны, не в этот файл.

## Блоки >= 32 байт (на момент составления)

| Адрес | Что это |
|---|---|
| `0x00412e41` (тело `0x00412e50`) | FontString paint/draw (vtable `0x5c8cdc`) |
| `0x00574380` (`EnterState` `0x005743a0`) | EnterState меню, switch на 19 случаев, таблица `0x575360` |
| `0x00573eae` (тело `0x00573eb0`) | драйвер Update/EnterState состояния меню (vtable `0x5e306c`) |
| `0x0059a69e` (тело `0x0059a6a0`) | пролог отрисовки Win3D / WinControl (vtable `0x5e5ce8`) |
| `0x005b8220` | не код: остаток PE Debug Directory / CodeView (NB10 + путь к `FreeLancer.pdb`) |
| `0x005a1cb8` (тело `0x005a1cc0`) | применение стиля NeuroNet-контрола (`FUN_004177b0` + id/scale) |
| `0x005753ac` (`0x5753b0`, `0x5753d0`) | флаги подписи и IDS-подпись + стиль |
| `0x00534ed3` | фрагмент середины функции (Ghidra не определил границу родителя), `vtable+0x150`, маски `0x103`/`0x803` |
| `0x0051f773` (тело `0x0051f780`) | маппер вида `[ecx+8]+0x1c` -> 0/1/2 (tradelane, vtable `0x5dc368`) |
| `0x00556ba9` (тело `0x00556bb0`) | `rep movsd` x12 в `dst+0x5c` (hotspot, vtable `0x5e12f8`) |
| `0x004c715f` (тело `0x004c7160`) | callback-трамплин `CALL [this+0x18](arg)` у настроек чувствительности (vtable `0x5d6d54`) |
